Career Journey

Systems and endpoints, then security.

My path into cybersecurity started with systems, endpoints, networks and users, not a classroom. Working IT support raised the questions that pulled me toward security: what happens when a system is compromised, what evidence does an attacker leave, how should an alert actually be investigated. This page separates where that foundation came from (professional and volunteer roles) from the hands-on security work I've built since (labs, projects and write-ups).
